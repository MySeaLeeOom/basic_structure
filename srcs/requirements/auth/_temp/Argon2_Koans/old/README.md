## Getting Started

- Make an html file: touch index.html then put a basic html template
(or type ! in vscode and then teb)

- Add <script type:"module" src="filepath"></script>
- `pnpm init`
- `pnpm add typescript`
- `pnpm exec tsc --init`
- add `"dev": "pnpm exec tsc *.ts" to package.json`
- open html file in the browser (this should work) or use live server in your favorite IDE
